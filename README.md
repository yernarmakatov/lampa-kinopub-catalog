# KinoPub Catalog for Lampa

Каталог KinoPub внутри Lampa без замены источника просмотра.

Схема: **KinoPub → обычная карточка Lampa → MODS → просмотр**.

## Установка

Добавьте в Lampa как плагин:

`https://cdn.jsdelivr.net/gh/yernarmakatov/lampa-kinopub-catalog@main/kinopub-catalog.js`

После перезапуска Lampa в левом меню появится **KinoPub**.

## Важный момент: авторизация

Этот каталог использует уже существующую сессию KinoPub из Lampa (`kp_token`).

Если KinoPub ещё не авторизован в Lampa, один раз установите источник KinoPub:

`https://mainsync-afk.github.io/lampa_kinopub/kp.js`

Затем:
1. Lampa → Настройки → KinoPub → Авторизоваться.
2. На телефоне откройте `https://kino.watch/device`.
3. Введите код из Lampa.
4. После успешного входа вернитесь в пункт **KinoPub** в левом меню.

MODS при этом можно продолжать использовать для просмотра как раньше.

## Что есть

- свежие, популярные и горячие фильмы/сериалы;
- полный каталог фильмов и сериалов;
- мультфильмы и аниме;
- документальные фильмы/сериалы, ТВ-шоу, концерты;
- продолжение просмотра;
- подборки KinoPub;
- закладки;
- история;
- карточки открываются как обычные TMDB-карточки Lampa, поэтому MODS остаётся основным источником просмотра.

Версия каталога: **0.2.0**

## MARVEL Story Order

Плагин строгого порядка просмотра Marvel:

`https://cdn.jsdelivr.net/gh/yernarmakatov/lampa-kinopub-catalog@main/marvel-story-order.js`

Включает:
- MCU в сюжетно-хронологическом порядке;
- Agent Carter;
- каноничную Defenders Saga по сезонам;
- старые Spider-Man фильмы перед No Way Home;
- Fox/X-Men и Deadpool как отдельный legacy-блок перед Deadpool & Wolverine;
- актуальную MCU до Spider-Man: Brand New Day (2026).

Левое меню: **MARVEL** → **Полный Story Order**.

Порядок намеренно не является чистой календарной хронологией для всех альтернативных вселенных: там, где есть мультивселенная/перезапуски/путешествия во времени, используется порядок, который лучше сохраняет сюжетные раскрытия и связи.
